# Lean Canvas - MachineGuard AI

*Student prototype. Everything below marked (potential) is a proposed future opportunity. There are no real customers, revenue, partnerships or deployments.*

| Block | Content |
|---|---|
| **Problem** | 1) Unexpected machine failures can lead to downtime. 2) Maintenance decisions may be reactive or schedule-based. 3) Machine operating data may not be translated into an accessible failure-risk indicator. |
| **Existing alternatives** | Scheduled maintenance; manual inspection; reactive maintenance; basic monitoring systems. |
| **Solution** | MachineGuard AI predicts failure risk, explains important model factors, analyses historical machine behaviour and discovers operating patterns. |
| **Key metrics** | Recall, precision, F1, ROC-AUC, failure-detection performance, prediction latency. |
| **Unique value proposition** | "Predict. Understand. Maintain." - an AI-powered early-warning prototype for industrial machine failure risk. |
| **Unfair advantage** | None claimed today. A future advantage *could* come from domain-specific historical data, real-time sensor integration, continuous model improvement and integration with maintenance workflows. |
| **Customer segments (potential)** | Maintenance teams; production managers; small/medium manufacturers; industrial analytics teams. *Proposed, not confirmed.* |
| **Channels (potential)** | Web application; industrial analytics teams; academic/technical demonstrations; future B2B deployment. |
| **Early adopters (potential)** | Organisations exploring AI-assisted predictive maintenance. |
| **High-level concept** | "An early-warning dashboard for machine failure risk" - risk estimate + explanation + maintenance insight from operating data. |
| **Cost structure** | Prototype development; cloud hosting; data storage; (future) IoT infrastructure; model maintenance. |
| **Revenue streams** | Student prototype: **no current revenue.** (Potential, future) B2B SaaS; enterprise deployment; predictive-maintenance analytics service. |

**SDG link:** supports data-driven industrial innovation related to SDG 9; no measured SDG impact is claimed.
